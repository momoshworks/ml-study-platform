## 📚 محتويات المنصة

### 1. الشرح التفصيلي للمحاضرات الأربع:
* **المحاضرة 01 (L01): The Machine Learning Landscape**
  * تعريفات تعلم الآلة (آرثر صامويل 1959، وتوم ميتشل 1997 وقاعدة E, T, P).
  * مثال مرشح البريد المزعج (Spam Filter) كأول تطبيق انتشاراً في التسعينات.
  * المنهج التقليدي مقابل منهج تعلم الآلة وتنقيب البيانات (Data Mining).
  * جدول التطبيقات الـ 13 والنماذج المخصصة لها (CNNs, RNNs, Transformers, Anomaly Detection, Clustering, RL).
  * أنواع أنظمة تعلم الآلة (Supervised, Unsupervised, Semi-supervised, Reinforcement Learning).
  * Batch vs. Online Learning ومفهوم Out-of-core learning ومعدل التعلم.
  * Instance-based vs. Model-based Learning ودوال المنفعة والتكلفة.
  * تحديات تعلم الآلة: البيانات السيئة (انحياز المعاينة وهندسة الخصائص)، والخوارزميات السيئة (Overfitting وحلوله والتنظيم Regularization، و Underfitting وحلوله).

* **المحاضرة 02 (L02): End-to-End Machine Learning Project**
  * الخطوات الثمانية للمشروع بالترتيب الدقيق.
  * دراسة مسألة أسعار منازل كاليفورنيا (California Housing) وخطوط الأنابيب (Pipelines).
  * مقارنة مقاييس الأداء: RMSE (المعيار الإقليدي $l_2$ norm) وحساسيته للشواذ مقابل MAE (معيار مانهاتن $l_1$ norm).
  * فحص البيانات وتفضيل المعاينة الطبقية (Stratified Sampling) على الدخل لتفادي انحياز المعاينة.
  * الاستكشاف البصري بالـ alpha والارتباطات وهندسة الخصائص.
  * تجهيز البيانات: حلول النواقص (`SimpleImputer`)، والترميز (`OneHotEncoder`)، والتحجيم (`MinMaxScaler` vs `StandardScaler`).
  * مقارنة النماذج والتحقق المتقاطع (10-fold Cross-Validation) والضبط الفائق (`GridSearchCV` و `RandomizedSearchCV`).

* **المحاضرة 03 (L03): Classification**
  * مجموعة بيانات MNIST (70,000 صورة، 784 خاصية، شدة من 0 إلى 255).
  * المصنف الثنائي لكاشف الرقم 5 باستخدام `SGDClassifier`.
  * لماذا تفشل الدقة (Accuracy) في البيانات غير المتوازنة (تجربة `Never5Classifier`).
  * مصفوفة الارتباك (Confusion Matrix) وأخطاء Type I و Type II.
  * **القوانين الرياضية العشرة الكاملة:**
    * Accuracy, Error Rate, Sensitivity/Recall/TPR, Specificity/TNR
    * Precision/PPV, Negative Predictive Value (NPV), Youden's Index (YI)
    * Matthews Correlation Coefficient (MCC), F1-Score (Harmonic Mean), Jaccard Index.
  * مقايضة الدقة والاستدعاء (Precision/Recall Trade-off) وعتبة القرار.
  * منحنى ROC ومساحة AUC والقاعدة الذهبية لتفضيل PR curve على ROC.
  * التصنيف المتعدد: OvR مقابل OvO وقانونها $N(N-1)/2$ واستخدامها مع SVM.
  * تحليل مصفوفة الأخطاء وتصنيف Multilabel و Multioutput.

* **المحاضرة 04 (L04): Training Models**
  * الصيغة الرياضية والاتجاهية للانحدار الخطي ودالة التكلفة MSE.
  * المعادلة الطبيعية (The Normal Equation): $\hat{\theta} = (X^T X)^{-1} X^T y$.
  * تفكيك القيمة المفردة SVD والمعكوس الزائف وتفوقه على المعادلة الطبيعية في معالجة المصفوفات الشاذة.
  * التعقيد الحسابي: $O(n^3)$ مقابل $O(n^2)$ وسرعة مرحلة التنبؤ الخطية.
  * خوارزمية التدرج التنازلي (Gradient Descent)، تأثير معدل التعلم، ودالة التكلفة المحدبة (Convex) وانعدام الصغرى المحلية.
  * أهمية تحجيم الخصائص للنزول السريع المباشر في الوعاء.
  * مقارنة الأنواع الثلاثة: Batch GD, Stochastic GD والـ Simulated Annealing، و Mini-batch GD وتسريع العتاد.
  * جدول المقارنة الشامل النهائي بين الخوارزميات الخمس.
