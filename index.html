المحاضرة 01

مشهد وتصنيف تعلم الآلة (The ML Landscape)

التعريفات الأساسية (سامويل، ميتشل)، لماذا نستخدم ML، التطبيقات الـ 13 ونماذجها، أنواع الأنظمة (إشراف، دفعات، نماذج)، والتحديات (بيانات سيئة، خوارزميات سيئة: Overfitting & Underfitting).

  • 📌 تعريف توم ميتشل (E, T, P) ومثال الـ Spam Filter
  • 📌 الفرق بين Supervised, Unsupervised, Semi-supervised, RL
  • 📌 Batch vs Online Learning ومفهوم Out-of-core
  • 📌 حلول الـ Overfitting والتنظيم (Regularization)
المحاضرة 02

مشروع ML عملي متكامل (End-to-End ML Project)

الخطوات الثمانية للمشروع، دراسة مسألة أسعار منازل كاليفورنيا، مقاييس الخطأ (RMSE vs MAE)، المعاينة الطبقية (Stratified Sampling)، استكشاف البيانات وهندسة الخصائص، وتجهيز البيانات والضبط الفائق.

  • 📌 الخطوات الثمانية بترتيبها للحفظ
  • 📌 مقارنة المعايير $l_2$ norm (RMSE) و $l_1$ norm (MAE)
  • 📌 معالجة النواقص (`SimpleImputer`) والترميز (`OneHotEncoder`)
  • 📌 Min-max scaling مقابل Standardization، و `GridSearchCV`
المحاضرة 03

التصنيف ومقاييس الأداء (Classification)

مجموعة بيانات MNIST، مصنف الـ SGD الثنائي لكشف الرقم 5، مصفوفة الارتباك (Confusion Matrix)، القوانين العشرة الكاملة لمقاييس الأداء، مقايضة Precision/Recall، ومنحنى ROC، واستراتيجيات OvR و OvO.

  • 📌 لماذا تفشل الدقة في البيانات غير المتوازنة (Skewed)؟
  • 📌 القوانين العشرة: Precision, Recall, F1-score, Specificity, MCC
  • 📌 منحنى ROC ومساحة AUC وقاعدة المقارنة مع PR Curve
  • 📌 استراتيجيات OvR مقابل OvO وقانون $N(N-1)/2$
المحاضرة 04

تدريب النماذج والتدرج التنازلي (Training Models)

الانحدار الخطي الرياضي، المعادلة المغلقة (Normal Equation) ومقارنتها بـ SVD، التعقيد الحسابي، وخوارزمية التدرج التنازلي (Gradient Descent)، والأنواع الثلاثة (Batch, SGD, Mini-batch) والـ Simulated Annealing.

  • 📌 المعادلة الطبيعية $\hat{\theta} = (X^T X)^{-1} X^T y$ وتفوق SVD عليها
  • 📌 دالة التكلفة المحدبة (Convex) وانعدام الصغرى المحلية
  • 📌 تأثير معدل التعلم $\eta$ والتحجيم السليم على سرعة التقارب
  • 📌 جدول المقارنة الشامل النهائي بين الخوارزميات الخمس

محاكي التدرج التنازلي التفاعلي (Gradient Descent Simulator)

شاهد كيف يؤثر معدل التعلم (Learning Rate $\eta$) على مسار النموذج في دالة التكلفة المحدبة (Convex Cost Function). لاحظ كيف يتصرف النموذج عند معدل صغير جداً، مثالي، أو كبير جداً!

الحالة: جاهز للمحاكاة.
دالة التكلفة (Cost Function $J(\theta)$) مسار المعاملات ($\theta$) القاع الأدنى (Global Minimum $\hat{\theta}$)
